Setup & Security Notes

How this works: login is verified by a small Cloudflare Worker that holds your real password (as a hash) and your GitHub token as server-side secrets — neither ever reaches this page or your browser's dev tools. A correct login returns a short-lived signed session token (2 hours).

Save Draft stores your edits in this browser's localStorage for an instant local preview only — nothing is sent anywhere.

Publish to GitHub sends your session token + the changed files to the Worker, which verifies the token, then uses the GitHub API to commit data.json (and any newly uploaded certificate images/PDFs, auto-placed under assets/certs/) directly to your repository in one atomic commit. GitHub Pages then rebuilds syedburhanss.online automatically — allow roughly 30–90 seconds.

To enable this, you must first deploy the Worker and set WORKER_URL near the top of this file's script — see the full setup instructions provided with this delivery.
